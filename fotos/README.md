# Fotos reais dos serviços

Crie uma pasta com o nome (slug) do serviço e coloque as fotos dentro. A primeira foto
(em ordem alfabética) de cada pasta é otimizada automaticamente no build e aparece no site.

| Pasta | Serviço |
| --- | --- |
| `desentupimento-de-esgoto/` | Desentupimento de Esgoto (também usada no topo da home) |
| `desentupimento-de-pia/` | Desentupimento de Pia |
| `desentupimento-de-vaso-sanitario/` | Desentupimento de Vaso Sanitário |
| `desentupimento-de-ralo/` | Desentupimento de Ralo |
| `limpeza-de-caixa-de-gordura/` | Limpeza de Caixa de Gordura |
| `desentupimento-de-coluna/` | Desentupimento de Coluna de Prédio |
| `hidrojateamento/` | Hidrojateamento |
| `desentupimento-de-tanque/` | Desentupimento de Tanque |

Para trocar uma foto já convertida, apague o `.jpg` correspondente em `src/assets/fotos/`.
Corte marcas d'água ("Shot on…") antes de subir.
